# Federato ISO / Verisk Executive Brief

Standalone GitHub Pages package for the Federato ISO / Verisk executive brief.

## Files

- `index.html` - publishable HTML page with inline CSS
- `assets/logo.svg` - local Federato logo asset used by the page

## Publish

Push this folder to a GitHub repository and enable GitHub Pages from the branch root, or copy these files into the repository root if the repo is dedicated to this page.
