# ISO Learning Wiki

Static GitHub Pages package for the ISO Learning Wiki.

## Publish

1. Create a new GitHub repository.
2. Upload the contents of this folder.
3. In GitHub, go to `Settings` -> `Pages`.
4. Set the source to `Deploy from a branch`.
5. Select the branch you uploaded to, usually `main`, and the root folder `/`.
6. Save.

GitHub Pages will serve `index.html` as the site home page.
